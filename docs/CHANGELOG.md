- **หน้าภาพรวม:** การ์ด "บัญชีใกล้ถูกระงับ" และ "คำขอบัญชีรอพิจารณา" (ผู้ดูแลส่วนกลาง 8 การ์ด 4 × 2) (`components/admin/Overview.tsx`)
- **ประวัติการใช้งานรายคน:** ปุ่ม "ดูประวัติการใช้งาน" ในหน้าแก้ไขผู้ใช้ + ไอคอนนาฬิกาในรายชื่อผู้ใช้ → `/admin/activity-logs?user=<ชื่อผู้ใช้>` (`UserTools.tsx`, `lists/pages.tsx`, `ListPage.tsx`)

- **นำเข้าผู้ใช้จาก Excel ใช้กฎตรวจข้อมูลชุดเดียวกับฟอร์ม:** เหตุผลรายช่องต่อแถว, เติม 0 หน้าเบอร์โทรที่ Excel ตัดหาย, ไฟล์ต้นแบบเพิ่มคอลัมน์ H ชื่อภาษาอังกฤษและคำอธิบายกฎ (`endpoints/importUsers.ts`, `migration/build_user_template.py`, `web/public/templates/user_import_template.xlsx`)

- **ภาพเด่นส่วนหัว:** อัปเดตกาฬสินธุ์ (KSN) และชลบุรี (CBI) จาก `image76/` คัดลอกไว้ใน `76province_hero/` ด้วย; `76province_hero/` ซิงก์ให้ตรงกับเว็บอีก 15 จังหวัด (CCO CMI CNT CPM CPN CRI CTI NMA NPM NPT NST NYK TAK TRG TRT) ภาพรุ่นเก่าย้ายไป `assets/hero-old/`

- **สิทธิ์ไฟล์ตามจังหวัด:** บทบาทระดับจังหวัดแก้/แทนที่ไฟล์ได้เฉพาะของจังหวัดตัวเอง (เดิมแก้ไฟล์จังหวัดอื่นผ่าน API ได้) อ่านได้เฉพาะฉบับปัจจุบันและเวอร์ชันเก่าของจังหวัดตัวเอง (`lib/provinceFiles.ts`, `collections/Content.ts`)
- **ชื่อเมนู:** "ประกาศป๊อปอัป" → "ประกาศ"; กลุ่ม "ระบบ" → "ผู้ใช้งาน" (ประวัติการใช้งานเดิมที่บันทึกส่วนของระบบเป็น "ประกาศป๊อปอัป" คงไว้ตามเดิม)

- **ชื่อในแอปยืนยันตัวตน (2FA):** จาก "บัญชีข้อมูลจังหวัด" เป็น "สนับสนุนบัญชีข้อมูล" แสดงเป็น "สนับสนุนบัญชีข้อมูล: <ชื่อผู้ใช้>" มีผลกับการตั้งค่า 2FA ครั้งใหม่ (`lib/auth.ts`)

### แก้บั๊ก
- **โหมดมืด** (ตรวจครบ 8 ธีม × 4 หน้า): ชื่อประเภทในตาราง "เอกสารล่าสุด" ความต่างสีเพียง 1.6–2.2:1 และตัวเลขในป้ายประเด็นที่เลือก 1.8:1 → ปรับเป็นสีอ่อนของหมวด / ตัวเลขเข้มบนพื้นสว่าง ผ่านเกณฑ์ WCAG ทุกข้อความแล้ว (`styles.css`)

- **ลบผู้ใช้ไม่ได้** ถ้าบัญชีเคยได้ลิงก์เปิดใช้บัญชี (ฐานข้อมูลปฏิเสธ) → ลบลิงก์ของบัญชีก่อนลบบัญชี (`collections/Users.ts`)
- **ไฟล์ `migration/import/province_managers_76.xlsx` ถูกเขียนทับเป็นแบบฟอร์มว่าง** เมื่อรัน `migration/build_user_template.py` (สร้างแบบฟอร์มใหม่ตอนเพิ่มคอลัมน์ชื่ออังกฤษ) → กรอกกลับครบ 76 แถว (`admin_{slug}`, "สำนักงานสถิติจังหวัด…", บทบาทผู้ดูแลจังหวัด) และแก้สคริปต์ให้สร้างไฟล์นี้เฉพาะเมื่อยังไม่มี **ควรเปิดตรวจไฟล์อีกครั้ง**
- **กฎชื่อในหลังบ้าน/นำเข้า Excel บังคับเว้นวรรค** ทำให้ชื่อสำนักงาน 76 แถวไม่ผ่านทั้งหมด → ไม่บังคับเว้นวรรคในหลังบ้าน (ฟอร์มขอใช้บัญชียังบังคับ) ตรวจตัวอย่างนำเข้าแล้ว พร้อม 76/76 (`lib/fieldRules.ts`)
- ชุดทดสอบ `check-public` ล้มถ้าโหมดไว้ทุกข์เปิดอยู่ก่อนทดสอบ → ปิดเองก่อนเริ่มและคืนค่าเดิมเมื่อจบ เพิ่มการตรวจระดับสีเทา (`scripts/check-public.ts`)
