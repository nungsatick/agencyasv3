- **การ์ดชุดข้อมูลรวมสองประเด็นไว้ในการ์ดเดียว** (เช่น กาฬสินธุ์ ปี 2568 เกษตร + ผู้สูงอายุ แสดง Template 1–3 ซ้ำสองชุด มีป้ายและลิงก์แค่ประเด็นแรก) เกิดกับ 20 การ์ดที่เอกสารจากเว็บเดิมไม่มีชื่อประเด็น → แยกการ์ดตามประเด็น เอกสารที่ยังไม่ระบุประเด็นจะรวมกับชุดของประเด็นในปีนั้นเฉพาะเมื่อเติม Template ที่ขาด (บางชุดระบุประเด็นไว้แค่ Template 1) ไม่อย่างนั้นแยกเป็นการ์ด "ชุดข้อมูล" ของตัวเอง การ์ดที่ไม่มีชื่อประเด็นแสดงชื่อ "ชุดข้อมูลประเด็น…" ผลรวมทั้งประเทศ: การ์ดที่ปนหลายประเด็น 20 → 0, การ์ดที่มี Template ซ้ำ 52 → 25 (ที่เหลือเป็นเอกสารที่ไม่มีทั้งชื่อประเด็นและประเด็น แยกไม่ได้)
- ลิงก์ "ดูแดชบอร์ดประเด็นนี้" ในการ์ดชุดข้อมูล: ถ้าปีนั้นไม่มีแดชบอร์ดของประเด็น จะลิงก์ไปปีที่ใกล้ที่สุดที่มี พร้อมบอกปี เช่น "(ปี 2568)" การ์ดที่เอกสารยังไม่ได้ระบุประเด็นยังไม่มีลิงก์ (`[province]/docs/page.tsx`)

- **ชื่อเมนู:** "ประกาศป๊อปอัป" → "ประกาศ"; กลุ่ม "ระบบ" → "ผู้ใช้งาน" (ประวัติการใช้งานเดิมที่บันทึกส่วนของระบบเป็น "ประกาศป๊อปอัป" คงไว้ตามเดิม)

- **ชื่อในแอปยืนยันตัวตน (2FA):** จาก "บัญชีข้อมูลจังหวัด" เป็น "สนับสนุนบัญชีข้อมูล" แสดงเป็น "สนับสนุนบัญชีข้อมูล: <ชื่อผู้ใช้>" มีผลกับการตั้งค่า 2FA ครั้งใหม่ (`lib/auth.ts`)

- ส่วน "ข้อมูลจากเว็บเดิม" ในฟอร์มเอกสารและแดชบอร์ด แสดงเฉพาะรายการที่ย้ายมาจากเว็บเดิม รายการที่สร้างใหม่ไม่เห็นกล่องว่างแล้ว ข้อมูลเดิมยังเก็บครบ (`collections/Content.ts`)

- ซ่อนแท็บ "API" (ข้อมูลดิบ JSON สำหรับนักพัฒนา) ในหน้าแก้ไขทุกเมนูและหน้าตั้งค่าเว็บ เปิดจากลิงก์ตรงก็ขึ้น "ไม่พบ" ระบบ API ที่หลังบ้านใช้ทำงานเหมือนเดิม (`payload.config.ts`)

- **การ์ดหน้าภาพรวมแบบใหม่** (`components/admin/Tile.tsx`): ไอคอน ตัวเลขมีจุลภาค คำอธิบายใต้ตัวเลข แถบความคืบหน้า (จังหวัดที่มีเอกสาร 76/76) สีตามสถานะ (ฟ้า = จำนวน, ส้ม = มีเรื่องค้าง, เขียว = ไม่มีค้าง) การ์ดที่กดได้มีลูกศรและยกขึ้นเมื่อชี้ ขนาดกะทัดรัดขึ้น มือถือแสดง 2 คอลัมน์
- ตารางภาพรวม 76 จังหวัด: ลิงก์ "เอกสาร · หน้าเว็บ" เปลี่ยนเป็นปุ่มไอคอน

- **แผนที่การเข้าชม** ในหน้าสถิติการเข้าชม (ส่วนกลาง): แผนที่ประเทศไทยตามขอบเขตจังหวัดจริง สีตามจำนวนเข้าชม จังหวัดที่มีผู้เข้าชมใน 15 นาทีล่าสุดมีจุดสีส้มกระพริบ กรอบขยายกรุงเทพฯ และปริมณฑล รีเฟรชเองทุก 1 นาที พร้อมรายการกำลังเข้าชมและ 10 อันดับ ไม่ต้องแก้ฐานข้อมูล ขอบเขตจังหวัดจาก geoBoundaries (ข้อมูล OpenStreetMap สัญญาอนุญาต ODbL ใส่ที่มาใต้แผนที่แล้ว) แปลงด้วย `migration/build_thai_map.py` เป็น `lib/thaiMapPaths.ts` (85 KB) (`components/admin/ThaiVisitMap.tsx`) ลองทำแบบหกเหลี่ยมก่อนแล้วเปลี่ยนตามผู้ใช้

### แก้บั๊ก
- **โหมดมืด** (ตรวจครบ 8 ธีม × 4 หน้า): ชื่อประเภทในตาราง "เอกสารล่าสุด" ความต่างสีเพียง 1.6–2.2:1 และตัวเลขในป้ายประเด็นที่เลือก 1.8:1 → ปรับเป็นสีอ่อนของหมวด / ตัวเลขเข้มบนพื้นสว่าง ผ่านเกณฑ์ WCAG ทุกข้อความแล้ว (`styles.css`)

- **ลบผู้ใช้ไม่ได้** ถ้าบัญชีเคยได้ลิงก์เปิดใช้บัญชี (ฐานข้อมูลปฏิเสธ) → ลบลิงก์ของบัญชีก่อนลบบัญชี (`collections/Users.ts`)
- **ไฟล์ `migration/import/province_managers_76.xlsx` ถูกเขียนทับเป็นแบบฟอร์มว่าง** เมื่อรัน `migration/build_user_template.py` (สร้างแบบฟอร์มใหม่ตอนเพิ่มคอลัมน์ชื่ออังกฤษ) → กรอกกลับครบ 76 แถว (`admin_{slug}`, "สำนักงานสถิติจังหวัด…", บทบาทผู้ดูแลจังหวัด) และแก้สคริปต์ให้สร้างไฟล์นี้เฉพาะเมื่อยังไม่มี **ควรเปิดตรวจไฟล์อีกครั้ง**
- **กฎชื่อในหลังบ้าน/นำเข้า Excel บังคับเว้นวรรค** ทำให้ชื่อสำนักงาน 76 แถวไม่ผ่านทั้งหมด → ไม่บังคับเว้นวรรคในหลังบ้าน (ฟอร์มขอใช้บัญชียังบังคับ) ตรวจตัวอย่างนำเข้าแล้ว พร้อม 76/76 (`lib/fieldRules.ts`)
- ชุดทดสอบ `check-public` ล้มถ้าโหมดไว้ทุกข์เปิดอยู่ก่อนทดสอบ → ปิดเองก่อนเริ่มและคืนค่าเดิมเมื่อจบ เพิ่มการตรวจระดับสีเทา (`scripts/check-public.ts`)
